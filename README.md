# Gradient Text

Create gradient text effects and copy the CSS code for your projects.

## How to Use

**Step 1:** Open `index.html` in your browser.

**Step 2:** An onboarding tutorial appears on first visit. Click **Open Generator** (or Skip).

**Step 3:** Enter your text in the Text field. The preview updates live.

**Step 4:** Pick 2-3 gradient colors using the color pickers.

**Step 5:** Adjust the **Angle** (0-360°) to change gradient direction.

**Step 6:** Adjust **Size** (20-80px) and **Weight** (300-900) for the text.

**Step 7:** Click a **preset** (Sunset, Purple Pink, Ocean, Fire, Galaxy, Mint) for quick styles.

**Step 8:** Click **Copy CSS** to get the ready-to-use code for your website.

## Features
- Live text preview
- 2-3 color gradient stops
- Adjustable angle (0-360°)
- Adjustable font size and weight
- 6 preset gradients
- Copy CSS code
- background-clip: text technique
